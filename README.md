# Birthday Invitation Page

A romantic static birthday invitation and date-planner page built with HTML, CSS, and JavaScript.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Local preview
Open `index.html` directly in a browser, or serve locally with:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment
This project is a static site and is ready to be imported into Vercel.

- Framework preset: Other
- Build command: leave blank
- Output directory: leave blank

## Email behavior
The page currently opens the user's mail app with a draft addressed to `villarizaced@gmail.com` for confirmation.
